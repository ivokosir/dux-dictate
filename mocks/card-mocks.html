What we picked

Card (top right)Resting: glowing mic + timer, one pill. Mouse on it: morphs into ✕ ✨ ✓ (✨ ghost, ✓ filled, 6 px gaps). No title, no text. Gone when done.
Card problemsRed pill with icon + short text + ✕. Clean-up failed (6 s), couldn't paste (8 s), no speech (3 s). Mic, ElevenLabs (with ⟳), no key: stay until ✕.
Bar micNo timer, fixed size. Fills teal while talking. Click = popout, right-click = start/stop. Only Mod+B (Mod+G goes away).
PopoutOne row: mic · Dictate (+ timer while talking) · ⚡ · fixed slot (Start / ✨ ✓ / Cancel / Retry). While working, the left icon spins. Nothing moves between states. Card hides while it's open.
Popout finishStart keeps it open. ✨ / ✓ there copy to the clipboard (no paste) and stay open; the new text lands on top of Recent with "Copied".
Live⚡ icon only, ghost, with tooltip. Locked while talking or working.
Recent = just filesNo app database. ~/Music/Dictations/ holds <time>.ogg, .txt and .clean.txt. The list reads the folder (last 20, 5 shown + "Show more").
What a row offersOnly audio → "Not transcribed" + ⟳ Transcribe. Every transcribed row has the same buttons: ✨ (clean up, or copy cleaned once it exists) and 📋 copy raw. The row's icon (📝 vs ✨) tells you which kind it is. Not transcribed → ⟳. Row click copies the best text. Always: folder, delete (to trash). 🧹 delete all asks first.
No time limitTalk as long as you like; audio is saved as you go.
